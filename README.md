
# LAST LEVEL TUITION CENTER SYSTEM

This is a simple Tuition Center Management System. It helps to manage students, teachers and  classes 

Link: https://github.com/joe-nguwo/LAST-LEVEL-TUTION-CENTER-SYSTEM-Website.git

Technologies: Svelte 5 for frontend and Golang Echo for backend.

## How to run:
1. git clone https://github.com/joe-nguwo/LAST-LEVEL-TUTION-CENTER-SYSTEM-Website.git
2. For backend  clone https://github.com/joe-nguwo/LAST-LEVEL-TUTION-CENTER-SYSTEM-BACKEND.git
3. For frontend - cd frontend, npm install, npm run dev
